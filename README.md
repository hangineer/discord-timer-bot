# 🤖 Disscord Simple Timer Bot

## Tech Stack
* Node.js (above v16.9.0)
* discord.js (v14)

## How to Use
1. **Invite Bot to your target Discord servers**
    🔗 Bot Invite Link
    https://discord.com/oauth2/authorize?client_id=1457385880464523294&permissions=274877908992&integration_type=0&scope=bot


2. **Call your bot**
   - Enter `/timer`
   - Enter countdown `minutes`（required）
   - Enter `title` (optional)

3. You will receive a "time is up" reminder
